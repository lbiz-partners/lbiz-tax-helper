# lbiz-tax-helper

세금정리도우미 공유 카드용 규칙 파일 저장소 준비본(v0.1-준비본).

올라갈 파일(저장소 루트, 평평하게):
- MANIFEST.txt
- README.md (이 파일)
- tax-rules.md (세금정리도우미 업무 규칙)
- tax-start.md (세금정리도우미 시작하기)

이 폴더의 `prep-docs/`·`01-설명-짧은안.template.txt`·`MANIFEST.template.txt`·시험 스크립트는 준비본용이며, 공개 저장소에 올리는 대상이 아니다(빌드 결과 `out/lbiz-tax-helper/`만 게시 후보).

소유자·태그·MANIFEST 해시는 아직 자리표시/빌드 인자다 [확인 필요].
기본 시험 RAW_BASE 예: `https://raw.githubusercontent.com/lbiz-partners/lbiz-tax-helper` (소유자 확정 [확인 필요]).
