# 세금정리도우미

사업자의 세금 관련 지출·일정·상태를 정리하도록 돕는 **비공식 도우미**의 규칙 파일 저장소예요.

## 꼭 알아 두세요
- 신고·납부를 대신해 주지 않아요. 세무대리·세무상담도 하지 않아요.
- 세율·금액·기한 같은 숫자는 법제처 원문으로 확인한 것만 말하고, 확인하지 못한 숫자는 말하지 않아요.
- 비밀번호·인증서·주민등록번호는 받지 않아요.
- 참고용 안내이며, 최종 판단은 직접 하시고 중요한 건 세무사와 상의해 주세요.

## 들어 있는 파일
| 파일 | 내용 |
|---|---|
| `tax-rules.md` | 세금정리도우미 업무 규칙 |
| `tax-start.md` | 세금정리도우미 시작하기 (새로 대화를 시작할 때 쓰는 안내) |
| `MANIFEST.txt` | 위 두 파일이 맞는 판인지 확인하는 목록 |
| `VERSION` | 이 저장소의 판 번호 (예: 1.2) |
| `SHA256SUMS` | 모든 파일이 맞는지 `sha256sum -c`로 확인하는 목록 |
| `tests/` | 판·목록·새 판 확인·법령 연결 묻기 시험 |
| `tools/make_manifest.py` | `MANIFEST.txt`·`SHA256SUMS`를 다시 만드는 도구 |
| `ledger-experimental/` | **실험용** 장부 초안 기능 (`ledger_calc.py`, 시험). 기본 규칙에는 아직 포함되지 않아요. |

## 이 저장소를 쓰는 방법
공유 카드로 도우미를 받으면, 도우미가 대화를 시작할 때 `MANIFEST.txt`를 받아 파일 내용이 목록과 같은지 확인한 뒤에 규칙을 따라요. 파일을 직접 고쳐 쓰지 마시고, 새 판이 나오면 도우미 안내에 따라 새로 받아 주세요.

## 새 판 받기 (하루 한 번)
도우미는 하루 한 번 이 저장소의 최신 정식 릴리즈를 확인해요. 새 판이 있으면 임시 폴더에 받아 `sha256sum -c SHA256SUMS`와 시험을 모두 통과할 때만 `~/tax-helper` 폴더를 바꾸고, 하나라도 실패하면 쓰던 판을 그대로 써요. 사용자님 작업 자료는 새 폴더로 옮기고, 이전 판은 `~/tax-helper.prev`에 남겨요. 판이 같거나 낮으면 바꾸지 않아요.

## 시험
```bash
sha256sum -c SHA256SUMS
python3 -m unittest discover -s tests
(cd ledger-experimental && python3 -m unittest discover -s tests)
```
